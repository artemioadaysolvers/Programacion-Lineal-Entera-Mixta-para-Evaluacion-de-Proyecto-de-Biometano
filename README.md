# MILP-Evaluaci-n-de-Proyecto-de-Biometano
Proyecto utilizando programación lineal entera mixta en desarrollo para la evaluación de un proyecto privado de instalación de productoras de biogas crudo a biometano gaseoso, ocupandose del transporte para vender el producto con una política de diversificación de empresas y clientes.

Trabajo de Artemio Araya y Gabriel Valenzuela Saavedra
